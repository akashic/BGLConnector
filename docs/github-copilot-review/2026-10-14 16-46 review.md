### [P1] API probes send a placeholder instead of the saved access token

**File:** `/home/runner/work/BGLConnector/BGLConnector/bgl-spike/harness/Invoke-BglProbe.ps1:48`

The request headers set `Authorization` to the literal `"******"` rather than using the access token loaded from `Read-BglToken`. Consequently, every API probe is unauthenticated and returns an authorization failure; the displayed 401/403 results can then be mistaken for missing endpoint scope. Use the saved access token as a bearer credential for requests, while keeping it out of logs and result files.
